Hour-by-hour forecast of Grand Theft Auto VI's launch-day Twitch concurrent viewers. The program anchors on the first hour's print and applies the launch-day shapes of 40+ past big game launches, weighted by how close each launch's opening hour was in size, and reports five quantiles per hour.

## Run it

```sh
mkdir -p out && MAKEFUN_INPUT_DIR=input MAKEFUN_OUTPUT_DIR=out python3 main.py
```
